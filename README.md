# Trinitee Website

A modern website built with React, Material-UI (MUI), and TypeScript.

## Features

- ⚛️ React 18 with TypeScript
- 🎨 Material-UI (MUI) for beautiful, responsive design
- 🚀 Vite for fast development and building
- 📱 Fully responsive design
- 🎯 Modern development setup with ESLint

## Getting Started

### Prerequisites

- Node.js 18 or higher
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Bonginkosi727/Trinitee-website.git
cd Trinitee-website
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
- `npm run type-check` - Run TypeScript type checking
